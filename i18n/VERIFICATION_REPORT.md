## 🔧 技术实现

### 依赖项

```go
// 外部依赖
"github.com/mattn/go-runewidth"  // Unicode 字符宽度计算

// 标准库
"os"       // 环境变量读取
"strings"  // 字符串处理
```

### 设计模式

- **单例模式** - 全局语言设置
- **策略模式** - 不同语言的翻译策略
- **工厂模式** - 语言检测和创建
- **回退模式** - 翻译缺失时的优雅降级

### 性能特性

- **O(1) 查找** - 使用 map 存储翻译
- **零运行时开销** - 编译时确定翻译表
- **懒加载** - 只加载当前语言的翻译
- **无锁设计** - 读取操作无需加锁
